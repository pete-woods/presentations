# presentations

Simple example of using Go's [present](https://godoc.org/golang.org/x/tools/present) tool.

## Install
Assuming you have Go installed already:
```shell
go install golang.org/x/tools/cmd/present
```

## Run

Run the following command, then navigate to [http://localhost:3999](http://localhost:3999) in your browser.
```shell
present
```

### With notes
Press `n` in the browser to launch a second synced window that shows the presenter notes.
```shell
present --notes
```
